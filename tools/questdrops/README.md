# Quest item drop chances (Nock 3.9.0)

`Nock/Data_QuestDrops.lua` is generated by `gen_questdrops.py`. Facts only, no invented numbers.

- **QuestieDB Forever** (`data/Forever/foreverQuestDB.lua`, `foreverItemDB.lua`, `foreverNpcDB.lua`, WoW Forever client data):
  which quests need which items (item objectives), which NPCs drop each item (`npcDrops`), NPC names and their main zone
  (area ID mapped to a uiMapID with `support/Forever/Zones/areaIdToUiMapId.lua`).
- **CMaNGOS classic-db** (Full_DB z2815 plus Updates, November 2026, local MariaDB `cm`):
  `creature_template.LootId` -> `creature_loot_template.ChanceOrQuestChance`.
  - Negative values are quest chances (the item drops only while you need it); the absolute value is used.
  - Grouped rows with chance 0 share what is left of their group equally: `(100 - explicit chances) / equal rows`.
    That is how the CMaNGOS loot code rolls a group, so it is derived, not guessed.
  - One level of `reference_loot_template` is followed only when both the reference row and the item row are
    ungrouped with explicit chances (`ref% x item%`).
  - Anything else is written as `false`: the addon then says "Drops from ..." without a %.

Size: only items a Forever quest asks for. General world drops (cloth, gems, potions, herbs) that drop from more
than 40 NPCs and are not quest-class items (item class 12) are left out; they are random loot, not "kill X for Y".

These are Classic numbers. The addon shows "Classic data; Forever may differ" under them.

Regenerate: `python3 tools/questdrops/gen_questdrops.py` (needs `/tmp/QuestieDB` and the `cm` database).
