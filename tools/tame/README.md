# Rare tameable beast spawn data (Nock 3.7.1)

`Nock/Data_TameSpawns.lua` is generated by `gen_tame370.py` from two sources, facts only:

- **QuestieDB Forever** (`data/Forever/foreverNpcDB.lua`, Forever client data): NPC rank (4 rare, 2 rare elite), spawn points and patrol waypoints per zone.
- **CMaNGOS classic-db** (`Full_DB/ClassicDB_1_12_1_z2815` plus every `Updates/*.sql` after 4493, loaded into a local MariaDB, November 2026). `cmangos_rares.json` holds, for each rare:
  - `resp`: `creature.spawntimesecsmin` / `spawntimesecsmax`
  - `n`: spawn points (`creature` rows for the entry, `creature_spawn_entry`, and `spawn_group_spawn` for spawn groups that hold the entry)
  - `pools`: `pool_creature_template` joined with `pool_template` (pool, chance, max_limit, members)
  - `groups`: creature `spawn_group` rows (Id, MaxCount, spawns, entries)
  - `single`: only one can be up and the spot is picked with equal weight (pool max_limit 1 with chance 0, or a spawn group with MaxCount 1)

The per-spot share (`pct = 100 / spots`) is written only when `single` is true **and** QuestieDB Forever lists the same number of spots. No source has placeholder data for these rares, so the chance a rare is up right now is shown as unknown. The respawn range is shown instead.

The JSON was exported once with SQL queries on those tables (local copy, not shipped). Regenerate the Lua with `python3 tools/tame/gen_tame370.py` after cloning QuestieDB to `/tmp/QuestieDB`.
