# Flight paths (Nock 3.10.0)

`Nock/Data_Flights.lua` is generated by `gen_flights.py`. Facts only, nothing guessed.

- **WoW Forever client data**, build `1.60.1.71037`, DB2 tables exported as CSV from wago.tools
  (`https://wago.tools/db2/<Table>/csv?build=1.60.1.71037`), kept in this folder:
  - `TaxiNodes.csv`: node ID, name, continent, world position, `Flags` (0x1 Alliance, 0x2 Horde, both = neutral).
  - `TaxiPath.csv`: direct flights (`FromTaxiNode` -> `ToTaxiNode`).
  - `UiMapAssignment.csv`, `UiMap.csv`: world -> map coordinates for zones and the two continent maps.
- **QuestieDB Forever** (`data/Forever/foreverNpcDB.lua`): flight master NPCs (`npcFlags` 0x08), names and where they stand.

A node is kept only when it is a player flight point (a faction flag, on Kalimdor or the Eastern Kingdoms, not a
quest, transport or test path) **and** a QuestieDB Forever flight master friendly to that faction stands within
60 yards of it. The pin goes where that flight master stands; the continent marker uses the node's own position.
Nodes without a matching flight master are left out. Routes are `TaxiPath` pairs with both ends kept, once per pair.

Left out in this build (no matching flight master in QuestieDB Forever yet): Nighthaven (druid-only points, 2),
the four Eastern Plaguelands towers (not flight masters), and the new Forever points in Mount Hyjal
(Summit of Eternity, Tainted Foothills) and Riverglades (Rog'mar, Farholde Keep). Regenerating after QuestieDB
Forever adds them picks them up.

Regenerate: `python3 tools/flights/gen_flights.py` (needs `/tmp/QuestieDB`).
